Frequently asked questions

Does it infer every nested type perfectly?

The lightweight generator infers primitive types and simple arrays. Nested objects use a generic record type, so review and refine the output for complex data.

Can JSON describe optional properties?

A single sample object cannot reliably tell which properties are optional across all possible responses. Mark optional properties manually when needed.

Is my JSON sent to a server?

The type inference runs locally in the browser. Avoid pasting secrets into any tool unless you have verified its handling.

Frequently asked questions

Does it work on every photo?

Results vary with hair, transparent objects, shadows and complex backgrounds. Inspect the output before publishing.

Which AI model should I choose?

The standard model uses the current isnet_fp16 output profile. The smaller isnet_quint8 model reduces first-download size, but quantization can change fine edges or small details. Test both on your own images if output quality is important.

How large is the first download?

In a November 6, 2026 cold-cache Chromium CI test, responses with known Content-Length values totalled at least 90.2 MiB for the standard model and at least 48.4 MiB for the smaller quantized model. These are measured lower bounds, not guaranteed transfer sizes; actual downloads vary by browser, cache and third-party assets. A separate confirmation is shown for each model in a tab session. The browser may cache assets for later use, and large images can use substantial memory.

Are my images uploaded?

The intended workflow processes the image in the browser. The AI library and model are loaded from a third-party CDN; review the tool and your browser network settings if you need strict offline guarantees.

Clean cut-outs for product photos and profile pictures

Removing the background of a photo means separating the subject, a person, a product or an object, from everything behind it and saving the result with a transparent background. The cut-out can then be placed on any colour, on a website banner, in a slide or on a marketplace listing without the old background showing through as a rectangle. This tool uses an in-browser AI model to find the subject and produce a transparent PNG, and the workflow is designed to keep image processing on your device.

Transparent cut-outs are used constantly in online selling and design. Shop owners photograph a product once and reuse the cut-out on every listing, banner and social post. Creators make profile pictures and stickers that sit cleanly over any background. Presenters drop a cut-out person or object into slides without a distracting room behind them.

How to use this tool

  1. Open the background-removal tool.
  2. Choose a clear image where the subject is easy to see.
  3. Pick the standard model for the current output profile, or the smaller quantized model for a lower first download.
  4. Confirm the first model download, run background removal, and download the transparent PNG.

Getting the best cut-out

The quality of the result starts with the photo. A subject that stands out from its background, with good light and sharp edges, is much easier to separate. Plain backgrounds work best. Fine hair, fur, transparent objects such as glass, shadows and complex backgrounds are the hardest cases, so inspect the output closely before publishing it. The smaller quantized model downloads faster, but it can change fine edges, so compare both models if quality matters. The first model download is large, tens of megabytes.

After you download the PNG

Open the result over a dark and a light background to check the edges, because a faint halo that is invisible on white can stand out on black. If an edge looks rough, try the other model or start from a clearer photo. Keep the original photo, because you cannot recover the background from the PNG alone. Does it work on every photo?

No. Results vary with hair, transparent objects, shadows and complex backgrounds. Clear subjects against plain backgrounds work best, so inspect the output before publishing it.

Which AI model should I choose?

Use the standard model when output quality matters most. Use the smaller quantized model when you want a lower first download, and accept that fine edges and small details may differ slightly.

Do I need to install anything?

No. The tool runs in your browser, but the AI library and model are loaded from a third-party CDN on first use, so the first run involves a large download that the browser may cache for later.

Frequently asked questions

Does it work on every photo?

Results vary with hair, transparent objects, shadows and complex backgrounds. Inspect the output before publishing.

Does the first run take longer?

Yes. The browser may need to download the AI model before processing begins, and large images can use substantial memory.

Are my images uploaded?

The intended workflow processes the image in the browser. The AI library and model are loaded from a third-party CDN; review the tool and your browser network settings if you need strict offline guarantees.

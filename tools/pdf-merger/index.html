Frequently asked questions

Can I merge several PDFs into one?

Yes. Select at least two PDF files and the tool will copy their pages into one output PDF.

Are the files uploaded?

The merger uses a browser-loaded PDF library and processes the files in your browser. The library itself is loaded from a third-party CDN.

Can I merge very large PDFs?

If the selected PDFs total more than 25 MiB, the tool shows a confirmation before loading the PDF library. PDF processing can use substantially more memory than the files’ combined size, especially on mobile. You can cancel or continue; smaller batches are safer on memory-limited devices.

Combining PDFs for work, study and sharing

A PDF merger takes several separate PDF documents and joins them into one file, keeping the pages in the order you choose. Instead of emailing five attachments or asking someone to open five files, you hand over a single document that reads from start to finish. This tool copies the pages of each selected PDF into one output document in your browser, using a browser-loaded PDF library.

Merging is useful in many everyday situations. Job seekers combine a cover letter, a CV and certificates into one application file. Students join chapters, notes and scanned handouts into a single study document. Offices merge invoices, receipts and contracts into one monthly file for accounting. Homeowners gather quotes, plans and permits for a renovation into one folder-ready document.

How to use this merger

  1. Select two or more PDF files from your device.
  2. Confirm the files are listed in the order you want them combined, because the tool merges them in the selected order.
  3. Choose Merge PDF files and save the resulting document.
  4. Open the merged file and check that every page is present and in the right order before you share it.

Getting a clean result

Order is the detail that matters most, so decide the sequence before you start: cover page first, then the main document, then supporting pages. If a file contains pages you do not need, extract only the pages you want first with the PDF splitter, then merge the trimmed files. Keep the original files until you have checked the merged result, because merging creates a new document and does not change your originals. Very large batches can use a lot of memory, especially on a phone, so if the tool warns you about a total above 25 MiB, consider merging in smaller groups.

Before you share the merged file

Open the result and skim it page by page. Check that scanned pages are the right way up, that no page is missing, and that the first page is the one a reader should see first. If the document contains personal details, confirm you are sending it to the right person, since a merged file is easy to forward.

How many PDFs can I merge at once?

Select at least two PDF files. There is no fixed count in the tool, but very large batches use more memory, so merge in smaller groups if the files are big or your device warns you.

Does merging change the quality of my pages?

No. The tool copies the pages from each selected PDF into the new document rather than re-rendering them, so text and images keep the quality they had in the originals.

Can I change the page order after merging?

Not in the merged file itself, so set the order before you merge. If you need to fix the order afterwards, split the merged PDF to pull out the pages you need and merge them again in the right sequence.

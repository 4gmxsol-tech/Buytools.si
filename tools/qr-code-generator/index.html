Create a QR code from a link or text

Paste the destination URL or a short text message into the QR tool, then generate the image. Before printing or sharing it, scan the result with a phone and confirm that it opens the intended destination.

  1. Open the QR code generator.
  2. Enter a complete URL (including https://) or short text.
  3. Select Generate QR code.
  4. Scan the generated code with a second device to test it.

Privacy note: The QR content is encoded locally in your browser. It is not sent to a QR-generation service. The browser downloads the QR library from jsDelivr; that request does not contain the text or URL you encode.

Where to use QR codes

  • Restaurant menus and product information.
  • Event invitations, posters and printed flyers.
  • Business cards and contact pages.
  • Public Wi-Fi instructions only when the network details are safe to share.

Use a high-contrast design, leave a clear margin around the code, and avoid making it too small for the expected scanning distance.

Static QR code checklist

A QR code stores the exact text or URL used to generate it. If you change the destination later, a static QR image does not automatically update. Use a URL you control if you expect the destination to change, and test the printed version before distributing it.

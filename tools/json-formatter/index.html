How to use the JSON formatter

  1. Paste or type your JSON into the input editor.
  2. Select Format to add readable indentation.
  3. Select Validate to check whether the JSON syntax is valid.
  4. Select Minify to remove unnecessary whitespace from valid JSON.
  5. Use Copy output to copy the result.

Common JSON syntax errors

  • Using single quotes instead of double quotes around strings and property names.
  • Leaving a trailing comma after the final property or array item.
  • Forgetting a comma between properties or array values.
  • Using comments, undefined or other JavaScript syntax that JSON does not support.
  • Leaving a closing brace or bracket out of place.

Frequently asked questions

Does formatting change my JSON data?

Formatting changes whitespace and indentation only. It does not change the JSON data structure.

How do I find an error in invalid JSON?

Paste the JSON and select Validate. The tool reports the detected error category and, when the browser provides a usable error position, the line and column to inspect.

Is my JSON uploaded to a server?

No. JSON parsing, formatting and minification run locally in your browser. The text is not sent to BuyTools.si by this page.

Can I minify JSON?

Yes. Select Minify to remove unnecessary whitespace while preserving valid JSON data.

How to use this tool

  1. Paste your JSON into the editor.
  2. Choose Format JSON to indent it, or Minify to remove unnecessary whitespace.
  3. If validation fails, read the error message and check the reported syntax.

For best results, use an up-to-date browser. Always review generated files before sharing or publishing them.

Frequently asked questions

Does formatting change the data?

Formatting changes whitespace and indentation, not the JSON data structure.

Can it validate JSON?

Yes. The formatter parses the input using the browser's JSON parser and reports syntax errors.

Is my JSON private?

The formatting operation runs locally in your browser and does not upload the text to BuyTools.si.

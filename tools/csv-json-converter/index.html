Convert CSV rows into JSON objects

CSV (comma-separated values) stores tabular data as rows and columns. JSON represents structured data as arrays, objects and values. Converting CSV to JSON is useful when importing spreadsheet data into an API, preparing a test fixture or moving a table into a JavaScript application.

The first row of the CSV input is treated as the header row. Each subsequent non-empty row becomes a JSON object, with the column headings used as property names. Values read from CSV are strings; the converter does not automatically infer numbers, dates or Boolean values.

Example CSV input

name,role,active
Ada,Engineer,true
Linus,Developer,true

Corresponding JSON output

[
  {
    "name": "Ada",
    "role": "Engineer",
    "active": "true"
  },
  {
    "name": "Linus",
    "role": "Developer",
    "active": "true"
  }
]

Notice that "true" is a string, not the JSON Boolean true. Convert value types in your application if your destination expects numbers, Booleans or dates.

Convert JSON arrays into CSV

For JSON to CSV conversion, provide an array of objects at the top level. The converter collects the property names used across the objects to form the CSV header. If an object is missing a property, that cell is left empty. Nested objects and arrays are serialized as compact JSON text inside the corresponding CSV cell.

When converting JSON to CSV, formula-like values are prefixed with a leading apostrophe as a compatibility safeguard for spreadsheet applications. Plain numeric values, including negative numbers such as -5, remain unchanged. Leading tabs, carriage returns and line feeds are also neutralized. Spreadsheet import behavior varies, so review the output in your target app before sharing it.

Example JSON input

[
  { "name": "Ada", "team": "Research" },
  { "name": "Linus", "team": "Engineering" }
]

Corresponding CSV output

name,team
Ada,Research
Linus,Engineering

How to use the converter

  1. Open the CSV ↔ JSON converter.
  2. Paste CSV with a header row, or paste a JSON array of objects.
  3. Choose CSV → JSON or JSON → CSV.
  4. Review the generated data and use Copy result.

CSV quoting and special characters

CSV fields may contain commas, quote marks or line breaks. Such fields should be enclosed in double quotes. A double quote inside a quoted field is represented by two consecutive double quotes.

name,description
Ada,"Research, mathematics and computing"
Sam,"He said ""hello"" to the team"

The converter supports quoted fields, doubled quote escaping and line breaks inside quoted fields. It reports unclosed quoted fields and rows whose number of columns does not match the header width. If a conversion fails, check the source around the reported issue and make sure every row follows the same column structure.

Common CSV to JSON conversion issues

  • Missing header row: the first row is always used as object property names.
  • Unexpected data types: CSV values become strings; type conversion is a separate step.
  • Inconsistent columns: every row should have the same number of fields as the header.
  • Unclosed quotes: close every quoted field and escape an internal quote by doubling it.
  • Empty rows: completely empty data rows are skipped when converting CSV to JSON.

CSV and JSON conversion FAQs

Does the CSV need a header row?

Yes. The first row is treated as the property names for the generated JSON objects.

Are numbers and Booleans automatically detected?

No. CSV fields are imported as strings. Convert them to numbers, Booleans or dates in your application when needed.

Can a CSV field contain a comma?

Yes. Put the field in double quotes. The converter also supports doubled double quotes inside quoted fields and line breaks within quoted fields.

What JSON input is supported for CSV output?

Use a top-level array of JSON objects. A single object, a primitive value or an array containing nested arrays is not accepted as the input shape for this conversion.

How are nested JSON values represented in CSV?

Nested objects and arrays are serialized as compact JSON text in their cell. CSV itself has no native nested-object data type.

Is my data uploaded?

No. This converter performs the conversion in the browser and does not send the pasted text to a conversion server.

Frequently asked questions

Does the CSV need headers?

The first CSV row is treated as column headers, so include a header row for meaningful object keys.

Does it support commas inside a quoted field?

The converter supports quoted fields and doubled quote escaping, and reports unclosed quoted fields or inconsistent row widths.

Should I paste private datasets?

Avoid pasting sensitive customer data or secrets into browser tools unless you have verified the processing and privacy behavior.

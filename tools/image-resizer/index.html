How to resize an image

  1. Select an image from your device.
  2. Enter the target width and height in pixels.
  3. Keep aspect ratio enabled to avoid stretching the image, or disable it only when distortion is acceptable.
  4. Choose Resize image and download the result.

Image processing runs in your browser. Very large images may use significant device memory.

Choosing image dimensions

Use the dimensions required by the destination platform whenever possible. Product images, profile photos and website thumbnails may have different size requirements. If you need a smaller file rather than different dimensions, use the image compressor as well.

Resizing changes pixel dimensions, while compression changes the way image data is encoded. They are related but different operations.

Frequently asked questions

Can I preserve the original proportions?

Yes. Keep aspect ratio enabled so the image is scaled proportionally.

Does the tool upload my image?

No upload is performed by the image resizer itself; processing uses the browser.

Will resizing reduce file size?

Often, but not always by the amount you expect. Use the compressor to control output quality and compare the resulting file size.

What can the CSV viewer do?

  • Open a local CSV file: select a .csv file up to 5 MiB. The browser reads it locally without uploading it.
  • Preview tabular data: read headers and records in a scrollable table, including wide datasets.
  • Search across rows: enter a term to keep rows where any cell contains that text.
  • Sort by column: click a column heading to switch between ascending and descending order. Numeric-looking values are sorted numerically when possible.
  • Export filtered results: download the visible, filtered rows as a CSV file that can be opened in spreadsheet apps.
  • Handle quoted CSV fields: commas, line breaks and escaped quotation marks inside properly quoted fields are supported.

How to use it

  1. Open the CSV Viewer & Sorter using the button above.
  2. Choose a .csv file up to 5 MiB, or paste CSV text including the header row. For example: name,age,city followed by one record per line.
  3. Choose the field separator (comma, semicolon or tab), then select Preview table. The tool checks that the rows have a consistent number of columns.
  4. Use the search field to narrow the table, and select a heading to sort that column.
  5. Choose Download filtered CSV to save the currently visible rows. Clear the search field to include all records again.

CSV format supported by this viewer

The viewer supports comma-, semicolon- and tab-separated values. Choose the field separator before previewing; the first row is used as column headers. Records may use CRLF, LF or CR line endings. Quoted fields, delimiters inside quoted fields, doubled quotation marks and line breaks inside quoted fields are supported. Invalid quote placement and characters after a closing quote are rejected instead of silently changing cell values. Each record must have the same number of fields as the header row. Filtered exports are normalized to comma-separated CSV.

  • Supported separators: comma, semicolon and tab. Select the separator that matches your file before previewing.
  • Export format: filtered downloads are normalized to comma-separated CSV.
  • Values: cells remain text; the viewer does not convert date strings, currency or Boolean text into typed values.
  • Sorting: numeric-looking values are compared numerically when possible; other values use locale-aware text sorting.

CSV character encodings

When you open a local CSV file, the viewer reads UTF-8 by default and recognizes UTF-8, UTF-16LE BOM and UTF-16BE BOM byte-order marks. Decoding is strict: malformed UTF-8 or UTF-16 sequences are rejected instead of silently replaced with the replacement character, so the viewer does not present altered cell text as if it were intact. Legacy encodings without a recognized BOM, such as some Windows code pages, are not auto-detected; save those files as valid UTF-8 before opening them. Pasted text is decoded by your browser before it reaches the viewer.

Spreadsheet formula safety on export

Spreadsheet applications can interpret CSV cells as formulas. The viewer prefixes a leading apostrophe to formula-like values, including values beginning with =, +, - or @; plain numeric values such as -5 remain unchanged. This is a compatibility safeguard, not a guarantee for every spreadsheet importer. Leading tabs, carriage returns and line feeds are also neutralized. Inspect the downloaded CSV in your target app before sharing it.

When is a CSV viewer useful?

CSV files are often used to exchange contact lists, product catalogs, exported analytics, survey responses, inventory, and application logs. A lightweight viewer helps you inspect a file quickly before importing it into a database or spreadsheet. Sorting and filtering can also make it easier to find a few records in a larger export without changing the original source file.

For larger or sensitive datasets, use a tool and device appropriate for the data classification. This page is designed for pasted text that fits comfortably in browser memory; it is not a database or a replacement for spreadsheet formulas.

CSV formatting tips

  • Include a header row so each column has a meaningful name.
  • Quote a field if it contains a comma, a line break or a double quote. Inside a quoted field, represent a literal double quote as two double quotes.
  • Keep each record's number of fields consistent.
  • Check date, decimal and identifier formats before importing data into another system. Different spreadsheet locales may interpret them differently.
  • Keep an untouched copy of the original file before cleaning or re-exporting data.

Troubleshoot common CSV import problems

If the preview does not match what you expected, check the separator, text encoding and quoting before changing the source file.

Every value appears in one column

The selected field separator may not match the file. Choose comma, semicolon or tab in the Field separator control, then preview again. Semicolons are common in some regional spreadsheet exports; tab-separated files use a tab between fields.

Text is garbled or the file is rejected

Save the file as UTF-8, or as UTF-16 with a valid byte-order mark. The viewer reads UTF-8 by default and recognizes UTF-8, UTF-16LE and UTF-16BE byte-order marks. Legacy encodings without a recognized mark are not auto-detected. Invalid byte sequences are rejected rather than silently replaced.

A row is rejected because it has a different number of columns

Each record must contain the same number of fields as the header row. Quote a field that contains the selected separator or a line break. Represent a double quote inside a quoted field as two double quotes. The parser rejects malformed quote placement and unexpected characters after a closing quote.

A line break appears inside a cell

That is expected when a line break is inside a properly quoted field. Line breaks inside quoted fields remain part of the cell; CRLF, LF and CR are recognized as record separators outside quoted fields.

Why does the filtered export use commas?

Filtered exports are normalized to comma-separated CSV, even when the source uses semicolons or tabs. If your spreadsheet expects another separator, choose the delimiter in its import dialog rather than assuming the downloaded file keeps the source delimiter.

Frequently asked questions

Is this CSV viewer free?

Yes. The viewer is free to use and does not require an account.

Does it upload my CSV?

No. Selected files are read with the browser File API, and pasted CSV text is processed in the page. This tool does not send the file or pasted table to a BuyTools.si processing endpoint. Avoid using sensitive data unless your organization permits it.

What is the maximum CSV file size?

The file picker accepts files up to 5 MiB. Pasted text has no separate application-level size limit and remains subject to available browser memory, so use a smaller sample on phones or lower-memory devices.

Can I export only the filtered rows?

Yes. Download filtered CSV exports the rows that match the current search, in the current sort order, with the header row included. The export uses comma separators.

Does the viewer modify my original file?

No. The original local file is only read. The viewer creates a separate download and does not overwrite the source file.

Does it convert dates, numbers or formulas?

No. Cell values remain text and formulas are not calculated. Numeric-looking values may be compared numerically for sorting, but the underlying cell text is not rewritten.

Does the CSV export protect against spreadsheet formulas?

The viewer prefixes a leading apostrophe to formula-like values and neutralizes cells beginning with a tab, carriage return or line feed. This is a compatibility safeguard, not a guarantee for every spreadsheet importer; review the downloaded file in your target app before sharing.

How many rows can I inspect?

There is no fixed row-count promise. Practical capacity depends on the CSV text size and memory available to your browser and device. For large datasets, use a spreadsheet or database application designed for them.

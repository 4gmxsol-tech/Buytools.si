What can the CSV viewer do?

  • Open a local CSV file: select a .csv file up to 5 MiB. The browser reads it locally without uploading it.
  • Preview tabular data: read headers and records in a scrollable table, including wide datasets.
  • Search across rows: enter a term to keep rows where any cell contains that text.
  • Sort by column: click a column heading to switch between ascending and descending order. Numeric-looking values are sorted numerically when possible.
  • Export filtered results: download the visible, filtered rows as a CSV file that can be opened in spreadsheet apps.
  • Handle quoted CSV fields: commas, line breaks and escaped quotation marks inside properly quoted fields are supported.

How to use it

  1. Open the CSV Viewer & Sorter using the button above.
  2. Choose a .csv file up to 5 MiB, or paste CSV text including the header row. For example: name,age,city followed by one record per line.
  3. Choose the field separator (comma, semicolon or tab), then select Preview table. The tool checks that the rows have a consistent number of columns.
  4. Use the search field to narrow the table, and select a heading to sort that column.
  5. Choose Download filtered CSV to save the currently visible rows. Clear the search field to include all records again.

CSV format supported by this viewer

The viewer supports comma-, semicolon- and tab-separated values. Choose the field separator before previewing; the first row is used as column headers. Quoted fields, delimiters inside quoted fields, doubled quotation marks and line breaks inside quoted fields are supported. Each record must have the same number of fields as the header row. Filtered exports are normalized to comma-separated CSV.

  • Supported separators: comma, semicolon and tab. Select the separator that matches your file before previewing.
  • Export format: filtered downloads are normalized to comma-separated CSV.
  • Values: cells remain text; the viewer does not convert date strings, currency or Boolean text into typed values.
  • Sorting: numeric-looking values are compared numerically when possible; other values use locale-aware text sorting.

CSV character encodings

When you open a local CSV file, the viewer reads UTF-8 by default and recognizes UTF-8, UTF-16LE BOM and UTF-16BE BOM byte-order marks. Files with a UTF-16 BOM are decoded before the CSV parser runs, so headers and values are not filled with null characters. Legacy encodings without a recognized BOM, such as some Windows code pages, are not auto-detected; save those files as UTF-8 before opening them. Pasted text is decoded by your browser before it reaches the viewer.

Spreadsheet formula safety on export

Spreadsheet applications can interpret CSV cells as formulas. The viewer prefixes a leading apostrophe to formula-like values, including values beginning with =, +, - or @; plain numeric values such as -5 remain unchanged. This is a compatibility safeguard, not a guarantee for every spreadsheet importer. Leading tabs, carriage returns and line feeds are also neutralized. Inspect the downloaded CSV in your target app before sharing it.

When is a CSV viewer useful?

CSV files are often used to exchange contact lists, product catalogs, exported analytics, survey responses, inventory, and application logs. A lightweight viewer helps you inspect a file quickly before importing it into a database or spreadsheet. Sorting and filtering can also make it easier to find a few records in a larger export without changing the original source file.

For larger or sensitive datasets, use a tool and device appropriate for the data classification. This page is designed for pasted text that fits comfortably in browser memory; it is not a database or a replacement for spreadsheet formulas.

CSV formatting tips

  • Include a header row so each column has a meaningful name.
  • Quote a field if it contains a comma, a line break or a double quote. Inside a quoted field, represent a literal double quote as two double quotes.
  • Keep each record's number of fields consistent.
  • Check date, decimal and identifier formats before importing data into another system. Different spreadsheet locales may interpret them differently.
  • Keep an untouched copy of the original file before cleaning or re-exporting data.

Frequently asked questions

Is this CSV viewer free?

Yes. The viewer is free to use and does not require an account.

Does it upload my CSV?

Selected .csv files are read with the browser File API; neither the selected file nor pasted CSV text is sent to a processing server by this tool. Parsing, filtering, sorting and export run locally. Avoid using sensitive data unless your organization permits it.

Does the CSV export protect against spreadsheet formulas?

The viewer prefixes a leading apostrophe to formula-like values such as =1+1, +SUM(...), -1+1 or @SUM(...); plain numeric values such as -5 remain unchanged. This is a compatibility safeguard, not a guarantee for every spreadsheet importer. Leading tabs, carriage returns and line feeds are also neutralized. Review the downloaded CSV in your target app before sharing it.

Can I open a file directly from my device?

Yes. Choose a .csv file up to 5 MiB. The browser reads it locally, then you can select Preview table. You can also paste CSV text directly. Larger files are rejected to avoid excessive browser memory use.

Which CSV character encodings are supported?

Local files are read as UTF-8 by default. UTF-8, UTF-16LE and UTF-16BE byte-order marks are recognized. Legacy encodings without a recognized BOM are not auto-detected; save those files as UTF-8 first.

What is the maximum CSV file size?

The file picker accepts CSV files up to 5 MiB. This limit helps avoid excessive memory use on phones and lower-memory devices. For larger datasets, use a local spreadsheet or database tool. Pasted text is still subject to your browser's available memory.

Can I export just the filtered rows?

Yes. The download button exports the table after the current search filter and sort have been applied, with the original header row included.

Does it modify my original file?

No. The tool works on the text you paste and creates a separate download. Your original file remains unchanged.

Does it support semicolon-separated or tab-separated files?

Choose comma, semicolon or tab in the Field separator control before previewing. The viewer preserves quoted delimiters inside cells and normalizes filtered downloads to comma-separated CSV.

Does it convert dates, numbers or formulas?

No. Cell values remain text. Numeric-looking values may be sorted numerically, but the viewer does not calculate spreadsheet formulas or rewrite data types.

How many rows can I inspect?

There is no fixed row-count promise. The practical limit depends on the size of the pasted text and the memory available in your browser and device. For very large datasets, use a database or dedicated data tool.

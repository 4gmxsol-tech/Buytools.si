How to compress multiple images

  1. Select multiple image files from your device.
  2. Choose JPEG quality; lower values usually reduce size more but may reduce image quality.
  3. Click Compress all images and wait while each file is processed.
  4. Download the ZIP archive and inspect the results before replacing originals.

Processing runs in your browser. Images are not sent to our server by this tool. Transparent areas are filled with white because JPEG does not support transparency.

Batch image compression for websites and product photos

Batch compression reduces repetitive work when preparing a collection of photos for a website, online store or upload workflow. Compare the output size and visual quality before publishing.

Large images can use significant memory on phones and older computers. Start with a small batch if your device has limited free memory.

Frequently asked questions

How many images can I process?

Up to 100 images per batch. Device memory may make smaller batches more suitable.

Does it preserve transparency?

No. JPEG output fills transparent areas with white.

Are files uploaded?

No. The image processing is local to your browser; the ZIP library is loaded from a third-party CDN.

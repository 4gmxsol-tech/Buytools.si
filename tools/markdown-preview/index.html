  1. Paste or type Markdown in the editor.

Frequently asked questions

Does it support all Markdown extensions?

This lightweight preview supports common headings, emphasis, inline code, links and simple lists; it is not a complete CommonMark renderer.

Is HTML in Markdown executed?

Raw HTML is escaped rather than interpreted, which helps prevent pasted markup from running in the preview.

Can I use it for GitHub README files?

It is useful for a quick draft, but GitHub may support additional Markdown extensions that this preview does not implement.

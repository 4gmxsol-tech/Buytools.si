How to build and test an API request online

When integrating with a web service, developers often need to send an HTTP request with a specific method, URL, headers and body. A request builder makes it easier to assemble the request and inspect what the server returns.

Open the API Request Builder →

1. Choose the HTTP method and endpoint

Start with the endpoint supplied by the API documentation. Choose the required method, such as GET, POST, PUT, PATCH or DELETE. Confirm whether the endpoint expects a query string, JSON body or another content type.

2. Add headers and request data

Set headers such as Accept and Content-Type when required. Add authorization only in a trusted environment and never share a request containing live credentials. For a JSON request, check that the body is valid JSON before sending.

3. Review the generated cURL command

Developer Studio can generate a cURL representation of the configured request. Review the URL, method, headers and body before copying it into a terminal or script. Treat any authorization header or token as a secret.

4. Send the request and inspect the response

When you explicitly press Send request, the browser sends the request to the endpoint you specified. The API server may respond with a status code, headers and a response body. A browser security rule called CORS can prevent JavaScript from reading a response even when the server receives the request.

Security and troubleshooting
  • Use test credentials and sandbox endpoints whenever possible.
  • Do not paste production API keys into shared devices.
  • Check the endpoint's authentication and rate-limit documentation.
  • If CORS blocks the response, use the API provider's approved client or a trusted backend environment.
  • Never send requests to systems you do not own or have permission to test.

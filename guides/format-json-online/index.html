What does a JSON formatter do?

JSON (JavaScript Object Notation) is a text format commonly used to exchange data between applications and APIs. A formatter adds indentation and line breaks so nested objects and arrays are easier to inspect. A minifier removes optional whitespace to make valid JSON more compact.

Format JSON in a few steps

  1. Copy your JSON into the BuyTools.si JSON formatter.
  2. Select Format JSON to add indentation or Minify to compact it.
  3. If validation fails, read the error and inspect nearby punctuation, quotes and brackets.

Common JSON mistakes

  • Using single quotes instead of double quotes around strings and property names.
  • Leaving a trailing comma after the final item in an object or array.
  • Using comments, undefined values or other JavaScript syntax that standard JSON does not support.
  • Leaving brackets or braces unmatched.

Protect sensitive data

Do not paste API keys, passwords, private customer data or production secrets into tools unless you understand where the data goes. The formatter on this site parses text in your browser and does not require an account. Still, verify sensitive-data handling in your own environment before using any online utility.

Frequently asked questions

Does formatting change JSON data?

Formatting changes whitespace and indentation, not the represented data, when the input is valid JSON.

Why is my JSON invalid?

Check double quotes, commas, colons, and matching braces and brackets. Standard JSON does not allow comments or trailing commas.

Is minified JSON better?

Minified JSON is smaller and can be convenient for transport, while formatted JSON is easier for people to read and debug.

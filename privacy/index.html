Privacy Policy

See how BuyTools.si tools handle files, text, third-party code, model downloads and browser storage.

Last updated: November 5, 2026

Overview

BuyTools.si provides browser-based utilities. This policy describes the site's intended data handling. Individual tools can behave differently, so read the notice shown near a tool before using it.

Files and text you enter

Many image and text operations are designed to run locally in your browser and do not require an account. The QR code generator is an exception: it sends the entered text or URL to an external image service to create the QR code. Other tools load code or model assets from third-party hosts when you start the relevant feature. Do not submit confidential documents, passwords, API keys or sensitive personal information unless you have verified the processing behavior described below.

Third-party code, model assets and browser storage

Third-party libraries are loaded on demand from your browser, rather than being downloaded on every page visit. These providers can receive ordinary connection metadata, such as your IP address, browser details, request time and requested resource URL.

  • QR code generator: the text or URL you enter is placed in the data query parameter of a request to https://api.qrserver.com/v1/create-qr-code/. The QR image is generated and returned by that provider. Do not use this feature for confidential text or private URLs.
  • PDF merge and split: the browser loads https://esm.sh/pdf-lib@1.17.1 when you run either operation. The current site code reads the selected PDFs in your browser and uses the library there; it does not send the PDF bytes to a BuyTools.si processing endpoint. The CDN receives the library request and standard connection metadata.
  • Batch image compression and resizing: the browser loads https://esm.sh/jszip@3.10.1 when it creates the downloadable ZIP. Image processing and ZIP assembly are performed in the browser by the current site code; the CDN receives the library request, not the selected image files.
  • Images to PDF: the browser loads https://esm.sh/jspdf@2.5.2 when you create a PDF. The selected images are read and placed into the PDF in the browser; the current site code does not send their bytes to a BuyTools.si processing endpoint.
  • Background removal: the browser loads https://esm.sh/@imgly/background-removal@1.5.5. The library also downloads its WebAssembly and model assets from IMG.LY's default static asset host, staticimgly.com; the first download can be large and may be cached by the browser. In a cold-cache Chromium test on November 5, 2026 using library version 1.5.5, the model host received 27 GET requests; 24 responses exposed Content-Length values totaling 94,553,445 bytes (about 90.2 MiB). Three responses did not expose a length, so this is a measured lower bound, not an exact or guaranteed download size. Actual transfer varies by browser, cache and library assets, and repeat visits may reuse cached files. The current site code passes the selected image to the browser-side library and does not directly upload it to a BuyTools.si processing endpoint. The CI audit used a generated synthetic image and observed only GET requests with no external request body; this is evidence for the tested version and workflow, not a guarantee about future third-party code. Because third-party code and model assets are involved, do not treat this feature as a guaranteed offline workflow.

The exact library versions above describe the current site implementation and may change when a tool is updated. Third-party providers control their own infrastructure and privacy practices. Check your browser's network activity and the provider's current terms if you need to verify every request or have strict data-handling requirements.

The site stores your display-theme preference in browser local storage under the key buytools-theme. This is a local interface preference, not an account profile. Before the first background-removal model download in a tab, the tool asks you to confirm the possible cold-cache transfer. The decision is stored only for that tab session in sessionStorage under buytools-background-removal-consent-v1; it is not an account identifier and is not sent to BuyTools.si. Declining stops before the IMG.LY library or model assets are requested.

Hosting and technical data

The site is hosted as a static website. The hosting provider may process technical information such as IP address, request time, browser details and requested paths for security, delivery and troubleshooting under its own policies.

Advertising and analytics

Advertising and analytics may be introduced as the site develops. If third-party advertising is enabled, providers may use cookies or similar technologies to deliver, limit or measure ads, subject to their policies and applicable law. This page should be updated to name the actual providers and describe any consent controls before those services are enabled. We do not claim that advertising is currently configured just because this policy describes possible future use.

External services

Links, libraries and services provided by third parties are governed by their own privacy terms. BuyTools.si does not control their independent practices.

Your choices and contact

You can avoid entering sensitive information, disable browser storage, and use browser controls to manage site data. For privacy questions, contact the project through the public issue tracker; do not post private personal details there. Applicable privacy rights depend on your location and the services in use.

Policy changes

This policy may change as tools, hosting, analytics or monetization features change. The updated date above should be revised when material changes are made.
